

\# AI Hotel Knowledge Assistant



A hotel knowledge assistant built with Python and FastAPI.



\## Current Features



\- REST API using FastAPI

\- JSON-based hotel FAQ knowledge base

\- Keyword-based question matching

\- Source references in responses

\- Fallback for unknown questions



\## Technologies



\- Python 3.13

\- FastAPI

\- Uvicorn



\## Getting Started



1\. Create a Python virtual environment.

2\. Install dependencies:



&#x20;  pip install -r requirements.txt



3\. Run the application:



&#x20;  python -m uvicorn main:app --reload



4\. Open http://127.0.0.1:8000/docs
