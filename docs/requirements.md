\# Enterprise Hotel AI Knowledge Copilot



\## 1. Business Problem



Hotel staff need to find accurate answers from hotel

policies and operational documents.



Searching documents manually takes time, and incorrect

answers can lead to poor guest experiences.



\## 2. Proposed Solution



Build an AI-powered knowledge assistant that retrieves

relevant hotel information and generates answers

supported by source documents.



\## 3. Initial Functional Requirements



FR-001: Accept questions through a REST API.



FR-002: Retrieve relevant hotel knowledge.



FR-003: Return answers with source references.



FR-004: Handle questions that cannot be answered.



FR-005: Support English and Japanese questions.



\## 4. Non-Functional Requirements



NFR-001: Keep API credentials outside source code.



NFR-002: Provide automated tests.



NFR-003: Record response latency.



NFR-004: Support local development without AWS.
